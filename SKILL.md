# Xiazhouqi Blue Journal

Create a clean, light information graphic that feels like a carefully arranged journal rather than a commercial poster. Preserve the user's source material, wording, and factual UI details.

Read [references/style-guide.md](references/style-guide.md) before designing or generating an image. Use the examples only as visual references; do not copy their subject matter or text into unrelated work.

## Core composition

Build the page from an off-white paper field, mist-blue glow, rounded white cards, one clear device or screenshot, and sparse handwritten marks. Use a large title, short supporting copy, and modular information blocks. Scenic photographs may appear inside a Polaroid, phone screen, or small journal insert, but a full-bleed photograph with only a title overlay is not this style.

## Non-negotiable rules

- Default to a **3:4 vertical canvas** unless the platform or user specifies another ratio.
- Keep the palette low-saturation: mist blue, milk white, pale cream, blue-gray, and only tiny warm accents.
- Establish one reading path: small category label, main title, short supporting line, then supporting content.
- Keep key text and faces inside the mobile safe area. Leave breathing room around every edge.
- Use paper, tape, arrows, stars, flowers, underlines, and sticky notes as accents only. Do not fill every empty area.
- Keep screenshots legible and factually faithful. Do not invent buttons, settings paths, prices, or interface states.
- Do not add “小岛周末”, account names, logos, or watermarks unless the user asks for them.
- Avoid saturated cyan, heavy gray overlays, hard black shadows, neon gradients, clutter, and generic sales-poster styling.

## Working method

1. Inspect every supplied image before editing.
2. Identify the main subject, required wording, output platform, ratio, and key screenshot or visual insert.
3. Draft the composition with the fewest elements needed to communicate the subject.
4. Generate or edit the image while preserving the original visual information that matters.
5. Review the final at phone size. Check title legibility, text accuracy, screenshot clarity, edge safety, and visual cleanliness.
6. Revise if the page feels gray, dirty, crowded, overly white, or visibly artificial.
