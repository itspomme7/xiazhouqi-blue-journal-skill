# 下周七 · 蓝色手帐视觉规范

这份规范用于生成或编辑「蓝色手帐」教程封面与信息图。它不是固定模板，而是一套稳定的审美判断：清透、温柔、有手作痕迹，同时保证信息能在手机上一眼读懂。

## 1. 视觉气质

核心感受：

- 雾蓝与奶白带来的清透感
- 纸张、便签、手写标记带来的轻手帐感
- 苹果产品图式的整洁和留白
- 旅行记录式的松弛，而不是促销海报式的用力

画面应该先让人觉得舒服，再让人读到信息。所谓“手帐”是细节语言，不等于满屏装饰。

## 2. 配色

| 角色 | 建议颜色 | 用法 |
| --- | --- | --- |
| 主背景 | `#F7FBFD` / `#FFFDFC` | 奶白纸面，不使用刺眼纯白 |
| 主蓝 | `#CFE8F7` / `#B8DBF0` | 雾蓝光晕、标题高亮、局部卡片 |
| 蓝灰 | `#6F91A8` / `#344654` | 手写标记、正文和小标签 |
| 奶油黄 | `#FFF2BE` | 便签或 1 个重点提示 |
| 柔粉橙 | `#F3C6AE` | 小星星、小花等极少量点缀 |
| 辅助绿 | `#CDE7D4` | 波浪线或次级提示，少量使用 |

控制原则：蓝白约占画面的 80%；黄、粉、绿共同不宜超过 20%。避免高饱和蓝、紫蓝霓虹和大面积深色块。

## 3. 版式结构

适合手机教程、App 技巧、操作路径、知识卡片。

### 推荐结构

1. 顶部放小型栏目标签或“建议收藏”等弱提示。
2. 中上区域放大标题，重点词用浅蓝笔刷底纹或下划线标记。
3. 中部只保留一个主视觉：手机界面、截图或关键图示。
4. 辅助步骤放入 1–3 张白色圆角纸卡，不要平均铺满。
5. 底部用便签、小提示或一句收尾解释完成阅读闭环。

### 卡片与阴影

- 圆角自然，不做厚重塑料质感。
- 卡片以奶白或半透明白为主。
- 阴影要轻、软、偏灰蓝，目的是形成纸张层次，不是悬浮按钮感。
- 同一页最多使用两种卡片形态。

### 截图处理

- 原始截图中的重要文字和入口必须真实、清晰。
- 可使用手机框或圆角裁切，但不能牺牲关键操作区域。
- 用箭头、描边框或淡色底强调目标，一页只突出 1–2 个重点。
- 涉及隐私的信息必须模糊或遮挡。

### 照片的使用边界

- 旅行或生活照片可以放进拍立得、手机屏幕或小型纸张卡片中。
- 照片是信息页中的一个模块，不能替代整套手帐结构。
- 普通全屏照片加半透明标题卡不属于这套蓝色手帐风格。

## 4. 字体与排版

- 主标题：圆润黑体、自然手写体或有轻杂志感的中文字体。
- 正文：清晰的黑体或接近手写但不影响辨识的字体。
- 英文：简洁无衬线字体，避免科技霓虹字体。
- 颜色：主标题用深蓝灰或炭灰，不使用纯黑大色块。
- 行距略松；中文标题不要挤成密集方块。

当生成工具无法稳定生成中文时，优先保留干净构图，再用后期排版补字；不要接受明显错别字作为成品。

## 5. 装饰元素

可选元素：纸胶带、便签、拍立得边框、手绘箭头、波浪线、星星、小花、勾选框、柔光斑。

使用限制：

- 每个信息区域最多配置 1–2 个装饰元素。
- 装饰不能压住人脸、标题、截图入口或重要景物。
- 花朵和星星只用于边角收尾，不形成主题图案。
- 箭头必须指向真实信息，不能只为好看而添加。
- 不使用卡通人物、表情包或过量少女贴纸，除非用户明确要求。

## 6. 生成提示词骨架

> 将提供的内容制作成 3:4 竖版蓝色手帐信息图。使用雾蓝、奶白和极少量奶油黄，采用轻柔纸张质感、白色圆角卡片、手写波浪线与简洁箭头。标题最醒目，主截图保持真实清晰，步骤按自然阅读顺序排布。整体清透、有留白、适合手机阅读，不要高饱和、不要厚重阴影、不要堆满贴纸。

## 7. 成品检查

- 缩小到手机预览时，3 秒内能否看到主题？
- 标题是否清楚，是否存在错字、乱码或错误路径？
- 蓝色是否清透，而不是发灰、发脏或荧光？
- 页面是否只有一个主视觉？
- 装饰是否可以再删掉一个？
- 截图、照片插图和信息卡是否清楚且层级明确？
- 四边是否留出平台裁切安全区？
- 是否擅自加入了“小岛周末”、水印或无关文案？
